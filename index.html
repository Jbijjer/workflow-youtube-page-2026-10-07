● Workflow d'agent

D'une vidéo YouTube
à une page web à partager

Sept étapes, un seul trajet : je récupère la vidéo, j'obtiens les mots, je résume, je construis la page, je la publie — et je vérifie le lien avant de te l'envoyer.

De l'URL à l'adresse partageable

Chaque étape produit une preuve. Si une preuve manque, on ne passe pas à la suivante.

Les sept étapes

Ce qui se passe, dans l'ordre

Chaque carte tient en une idée : l'action, puis la preuve qui autorise à continuer.

1

Trouver la vidéo

J'identifie la chaîne, puis je lis son flux RSS pour prendre la vidéo la plus récente — un titre, une date convertie à ton fuseau.

✓ videoId + titre + date retenus
2

Chercher les mots

Je demande les sous-titres de la vidéo. S'ils existent, le transcript est là en quelques secondes.

✓ transcript non vide
seulement si besoin 3

Écouter, si muet

Pas de sous-titres ? Je télécharge l'audio, je le convertis en 16 kHz mono, puis je le transcris localement (Whisper).

✓ transcript couvre la durée réelle
4

Résumer en 5 points

Je lis le transcript et j'écris exactement 5 points — chacun un titre court et 2-3 phrases factuelles. Les chiffres restent tels quels.

✓ 5 points auto-suffisants
5

Construire la page

Un petit fichier de description, un gabarit : il en sort une page HTML autonome — un seul fichier, sans dépendance.

✓ titre + 5 points + balises de partage
6

Publier

La page part sur un hébergement statique public. Un simple git push + activation, et une adresse publique apparaît.

✓ URL renvoyée par l'hébergeur
7

Vérifier le lien

J'ouvre l'adresse pour de vrai : code 200, bon titre, page qui s'affiche sans texte coupé. Jamais d'annonce sans ce contrôle.

✓ 200 + rendu conforme

L'embranchement clé

Et s'il n'y a pas de sous-titres ?

Ce n'est pas une panne : c'est le chemin normal d'une vidéo sans sous-titres. On bascule sur l'écoute.

Dans les deux cas, on repart avec le même objet : un transcript de texte exploitable.

Les garde-fous

Ce qui pourrait mal tourner (et comment je le gère)

Un workflow ne vaut que par ses pièges anticipés.

Le réseau qui bloque les médias

La page YouTube s'ouvre mais tout téléchargement échoue ? Je force la résolution DNS des hôtes vidéo via un service chiffré, sans droits admin.

Vidéo sans sous-titres

C'est normal, pas un bug. Je bascule sur l'écoute au lieu de réessayer d'autres sources de sous-titres.

Transcription : noms et chiffres

Une transcription vocale peut se tromper sur un nom propre. J'affiche alors une réserve de méthode, jamais une certitude inventée.

Lien qui n'existe pas encore

Un hébergement public met jusqu'à une minute à répondre. Un premier 404 est banal : je boucle jusqu'à obtenir 200 avant d'annoncer quoi que ce soit.

Partage sans image

J'associe toujours l'image de la vidéo à la page, sinon l'aperçu du lien sort nu dans une conversation.

Contenu public

La page est publique : je vérifie qu'aucune donnée privée n'y figure. Pour de l'actualité, c'est sans risque.
